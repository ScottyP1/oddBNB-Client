A **portfolio-grade frontend** for a boutique stays marketplace.

oddBNB focuses on **cinematic browsing, rich listing pages, and a host-first publishing experience**.
The application integrates with a **Spring Boot backend API** and uses **AWS S3 presigned uploads** for scalable image handling.

# Highlights

- Curated landing page with themed categories and featured stays
- Listings grid with skeleton loading states
- Rich listing detail layout with gallery, amenities, and booking panel
- End-to-end host flow: create, edit, and delete listings
- Image uploads via **AWS S3 presigned URLs**
- Favorites system with optimistic UI updates
- Toast notifications for user feedback
- Authentication flows: register, login, forgot password, reset password
- Profile dashboard with hosted listings and saved favorites

# System Architecture

```
Frontend (React + TanStack)
        │
        │ REST API
        ▼
Spring Boot Backend
        │
        │ Presigned URLs
        ▼
AWS S3 (Image Storage)
        │
        ▼
MySQL Database
```

Images are uploaded **directly to S3** using presigned URLs generated by the backend.
This keeps uploads fast and prevents large files from passing through the API server.

# Architecture Notes

### Routing

File-based routes powered by **TanStack Router**.

```
src/routes/
```

Example routes:

```
/
/login
/register
/listings/$listingId
/profile
/dashboard
```

---

### Data Layer

API requests live in:

```
src/api/
```

React Query hooks live in:

```
src/hooks/
```

These manage:

- caching
- loading states
- background refetching
- optimistic updates

# API Configuration

The frontend communicates with:

```
https://api.theoddbnb.com
```

```
src/api/client.ts
```

JWT tokens are attached automatically using interceptors.
